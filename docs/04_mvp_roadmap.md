# MVP 범위 및 로드맵

## 1. 개발 원칙

처음부터 모든 기능을 구현하지 않고, 실제 업무에 필요한 핵심 기능부터 단계적으로 개발한다.

우선순위는 다음과 같다.

1. 재고 정합성
2. 주문/출고 흐름
3. 이력 추적
4. 사용 편의 기능
5. 통계/자동화 기능

## 2. 1차 MVP: 재고 관리 기반

목표는 항원별 LOT 재고를 정확히 등록하고 조회하는 것이다.

### 포함 기능

- 로그인
- 항원 관리
- LOT 재고 등록
- 재고현황 조회
- 유통기한 임박 조회
- 재고 부족 조회
- 입고 이력 생성
- 재고 조정
- 재고 이동 이력 조회

### 제외 기능

- 주문 등록
- 출고 자동 처리
- 엑셀 다운로드
- 바코드/QR
- 알림 자동 발송

## 3. 2차 MVP: 주문/출고 연결

목표는 2층 주문관리와 1층 출고업무를 시스템으로 연결하는 것이다.

### 포함 기능

- 거래처 관리
- 주문 등록
- 주문상세 등록
- 출고대기 주문 목록
- FEFO LOT 자동 배정
- 출고 처리
- 재고 자동 차감
- 출고 이력 저장
- 주문 상태 변경

## 4. 3차 MVP: 운영 편의 기능

목표는 실제 운영 편의성을 높이는 것이다.

### 포함 기능

- 출고 취소
- 재고 복구 이력
- 권한 기반 엑셀 다운로드
  - `/lots`, `/movements` 현재 검색조건 바로 내보내기
  - `/exports`에서 재고·이력 개별 또는 선택 통합 파일 생성
  - 이력 기간·구분 필터와 생성 정보·감사 로그 제공
  - 시트당 10,000건 및 파일당 4,000,000바이트 제한
  - DB 조회 실패 시 예시 데이터 없는 실패 처리
- 대시보드
- 권한 관리 화면
- 유통기한 임박 알림
- 재고 부족 알림
- 거래처별 출고내역 조회

## 5. 4차 개선: 확장 기능

장기적으로 필요한 경우 다음 기능을 검토한다.

- 바코드/QR 기반 출고 확인
- 거래처별 출고내역 PDF 생성
- 월별 출고 통계
- 항원별 판매/출고 추이
- 재고 예측
- 외부 주문 포털
- 모바일 최적화 화면

## 6. 단계별 완료 기준

| 단계 | 완료 기준 |
|---|---|
| 1차 MVP | 항원/LOT 재고 등록 및 조회 가능, 재고 이력 저장 가능 |
| 2차 MVP | 주문 등록 후 출고 처리 시 재고 자동 차감 가능 |
| 3차 MVP | 운영자가 대시보드와 권한·감사·용량 제한이 적용된 엑셀 다운로드로 업무 처리 가능 |
| 4차 개선 | 바코드/통계/외부 연동 등 확장 가능 |
